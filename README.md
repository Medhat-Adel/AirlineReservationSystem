# Airline Reservation and Management System

A console-based Airline Reservation and Management System developed in C++17.

## Technologies

- C++17
- Object-Oriented Programming
- STL
- Smart Pointers
- Lambda Expressions
- JSON
- CMake
- Make
- Git

## Main Features

- User Authentication
- Role-Based Access Control
- Flight Management
- Aircraft Management
- Crew Assignment
- Flight Reservation
- Seat Selection
- Payment Simulation
- Passenger Management
- Loyalty Program
- Check-In
- Boarding
- Maintenance Tracking
- Reporting and Analytics
- JSON Data Persistence
